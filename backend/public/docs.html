SwiftUI + Node.js Agent API

The application is a native SwiftUI app. Build it in Xcode on macOS. This page documents the backend running on Windows, macOS or Linux.

GET /api/health · POST /api/agent/query · POST /api/agent/stream

JSON input: {"prompt":"Hello world!"}; trimmed 1–4000 characters, actual body ≤32KiB.

Stream sends SSE message/error/done. Final result plus done is required. Missing model key returns query503 or stream error without done.

OpenAPI JSON · Workflow SVG · Editable PlantUML

Only backend/.env holds the Anthropic API key. Native clients need no browser CORS configuration. Local API has no end-user authentication; use an authenticated HTTPS ingress before remote exposure.
